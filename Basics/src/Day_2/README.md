# Day 02 — Arrays

## Topics Covered

- Two Pointers
- Move Zeroes
- Remove Duplicates
- Sliding Window
    - Fixed Size
    - Variable Size

## Key Concepts

### Two Pointers
Used to process arrays efficiently using two indices, reducing unnecessary traversal.

**Time:** `O(n)` | **Space:** `O(1)`

### Move Zeroes
Rearranged the array in-place while maintaining the relative order of non-zero elements.

**Time:** `O(n)` | **Space:** `O(1)`

### Remove Duplicates
Used a two-pointer approach to remove duplicates from a sorted array in-place.

**Time:** `O(n)` | **Space:** `O(1)`

### Sliding Window
Used for contiguous subarray problems by maintaining and updating a dynamic window.

- **Fixed Size:** Window size remains constant.
- **Variable Size:** Window expands and shrinks based on a condition.

**Typical Time:** `O(n)`

## Key Takeaway

Learned to identify and apply **Two Pointer** and **Sliding Window** patterns to optimize array and subarray problems.
